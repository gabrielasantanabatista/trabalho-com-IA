CodeDNA - Perfil do Desenvolvedor
Sobre o Projeto
CodeDNA é uma aplicação web interativa que realiza uma análise do perfil profissional do desenvolvedor através de um questionário dinâmico. O sistema apresenta perguntas sobre abordagens de trabalho, resolução de problemas e preferências técnicas, gerando um diagnóstico personalizado com base nas respostas do usuário.

Tecnologias Utilizadas
HTML5: Estruturação da página e componentes

CSS3: Estilização avançada com variáveis CSS, efeitos de gradiente e transições suaves

JavaScript: Lógica de interação, gerenciamento de estado e manipulação do DOM

Google Fonts: Fontes Inter e Chakra Petch para tipografia profissional

Funcionalidades
Questionário Dinâmico: Apresentação sequencial de perguntas com alternativas

Análise Personalizada: Geração de um perfil único baseado nas escolhas do usuário

Feedback Visual: Transições suaves e efeitos de hover para melhor experiência

Reinício do Quiz: Opção para refazer a análise a qualquer momento

Design Responsivo: Adaptação para diferentes tamanhos de tela
